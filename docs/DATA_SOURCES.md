# Data sources

AI disclosure: written with help from Claude (Anthropic); reviewed by the team.

All fire data come from NASA FIRMS (Fire Information for Resource Management System), https://firms.modaps.eosdis.nasa.gov .
The files were requested with the FIRMS archive download tool in JSON format. The folder names (`DL_FIRE_...`) are generated by FIRMS.

| Product (config id) | Sensor and satellite | Resolution | Folder in `data/raw/` | Used for |
|---|---|---|---|---|
| MODIS Collection 6.1 (`modis`) | MODIS on Aqua (Terra is in the files but is removed) | about 1 km | `DL_FIRE_M-C61_817682` | legacy sensor |
| VIIRS S-NPP, Collection 2 (`viirs_snpp`) | VIIRS on Suomi NPP | 375 m | `DL_FIRE_SV-C2_817684` | new sensor |
| VIIRS NOAA-20, Collection 2 (`viirs_noaa20`) | VIIRS on NOAA-20 | 375 m | `DL_FIRE_J1V-C2_817683` | downloaded, not used (role: reserve) |

Each folder has an archive file (`fire_archive_...json`, standard processing) and a near-real-time file (`fire_nrt_...json`).
NRT records are used only for days after the archive ends.

Area of the download: Australia (latitude about -43.6 to -9.2, longitude about 113.1 to 153.6).
The project analyses one region of it, set in `shared/project_config.json` (`regions`).
In the current region, after the filters, 5,525,697 detections remain (MODIS Aqua and VIIRS S-NPP).

## Fields used

`latitude`, `longitude`, `acq_date`, `acq_time`, `satellite`, `confidence` (MODIS: a number 0 to 100; VIIRS: a letter l, n or h),
`type` (FIRMS fire type; 0 is a presumed vegetation fire: check the FIRMS documentation).

## The data are not in the repository

The raw files are very large. To reproduce the results, download the same products from FIRMS (same area and dates), put the
files in `data/raw/<folder>/` with the names above, and run `python3 pipeline/run_all.py`.
The generated files in `web/public/data/` are committed, so the web page works without the raw data.
